Countdown for Events

Repository: hamzasiddiqui10/countdown_for_events

Description

A Flask web application that allows users to create, manage, and track countdown timers for their upcoming events. Features user authentication, real-time countdown displays, and event management capabilities built with Python, Flask, and SQLite.

Key Features

  • User Authentication — Secure account registration and login system
  • Event Management — Create, edit, and delete personal events
  • Live Countdown Timers — Real-time countdown display for each event
  • Event Persistence — Events are stored in SQLite database and persist across sessions
  • Responsive Design — Works seamlessly on desktop and mobile devices
  • Intuitive Interface — Simple, clean UI for easy event tracking

Technology Stack

  • Backend: Flask (Python web framework)
  • Database: SQLite (lightweight, file-based)
  • Frontend: HTML, CSS, JavaScript
  • Authentication: Flask-Login with session management

Getting Started

To run this project locally:

  1. Clone the repository from GitHub
  2. Install dependencies: pip install flask flask-login
  3. Run the Flask application: python app.py
  4. Open your browser to http://localhost:5000
  5. Create an account and start tracking your events

Usage

After logging in:

  • Click "New Event" to create a countdown
  • Enter event name and date/time
  • View live countdown timer on your dashboard
  • Edit or delete events as needed
