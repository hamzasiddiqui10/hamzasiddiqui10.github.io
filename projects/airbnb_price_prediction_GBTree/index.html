Airbnb Price Prediction (GBTree)

Repository: hamzasiddiqui10/airbnb_price_prediction_GBTree

Description

A machine learning project that predicts Airbnb listing prices in Berlin using the CatBoost gradient boosting algorithm. This project demonstrates a complete data science workflow including exploratory data analysis, feature engineering, model training, hyperparameter tuning, and comprehensive evaluation.

Key Features

  • Comprehensive EDA — In-depth exploratory data analysis with visualizations
  • Feature Engineering — Strategic feature creation and transformation for improved model performance
  • CatBoost Model — Gradient boosting implementation optimized for categorical features
  • Hyperparameter Tuning — Grid search and cross-validation for optimal model configuration
  • Model Evaluation — Multiple metrics including RMSE, MAE, and R² score
  • Production-Ready Code — Clean, documented code following best practices

Dataset

The project uses a Berlin Airbnb dataset containing:

  • Multiple listing features (room type, neighborhood, amenities, reviews, etc.)
  • Target variable: nightly price in EUR
  • Mix of numerical and categorical features
  • Real-world data requiring preprocessing and cleaning

Modeling Approach

The project follows a structured machine learning pipeline:

  1. Data Loading & Exploration: Understand data shape, missing values, distributions
  2. Data Cleaning: Handle missing values, outliers, and data inconsistencies
  3. Feature Engineering: Create derived features, encode categorical variables
  4. Model Training: Train CatBoost model with train/test split
  5. Hyperparameter Tuning: Optimize model parameters using cross-validation
  6. Evaluation: Assess model performance on test set and make predictions

Results

The CatBoost model achieves strong predictive performance on the Berlin Airbnb pricing task, with detailed metrics and visualizations available in the notebook. Feature importance analysis reveals which listing attributes most significantly influence price predictions.

Technologies & Libraries

  • Python — Primary programming language
  • CatBoost — Gradient boosting framework
  • Pandas — Data manipulation and analysis
  • NumPy — Numerical computations
  • Scikit-learn — Model evaluation and preprocessing utilities
  • Matplotlib & Seaborn — Data visualization

How to Run

  1. Clone the repository from GitHub
  2. Install dependencies: pip install catboost pandas numpy scikit-learn matplotlib seaborn
  3. Run the Jupyter notebook or Python script to train the model
  4. View predictions and evaluation metrics
  5. Use the trained model for price predictions on new listings
